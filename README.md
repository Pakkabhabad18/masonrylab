# MasonryLab

Interactive 2D masonry wall behaviour and failure visualizer (React + TypeScript + Vite + Tailwind).
Qualitative teaching tool: no structural calculations, no solver, not validated against experiments.

    npm install
    npm run dev      # local
    npm run build    # type-check + production build into dist/

Deploy: push to GitHub and import in Vercel (Framework: Vite, build `npm run build`, output `dist`).
